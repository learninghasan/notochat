# NotoChat Copilot

Load this directory as an unpacked Manifest V3 Chrome extension. Setup, permissions, limitations and verification status are in [the operator guide](../docs/OUTREACH_META_AND_COPILOT.md#chrome-copilot-installation).

This extension uses your existing signed-in NotoChat tab, an explicitly selected business/customer, and only summary/draft/question APIs. It never sends replies, places orders, or stores auth tokens. Source is implemented; real Chrome installation and Web Store publication have not been performed.
